# B站直播间亲密度面板

- 在直播间顶栏增加一个按钮，能在任何状态(直播中/未开播/未关注)直播间打开亲密度面板

## 安装

需要先安装 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)。

点击下方表格中的链接即可安装：

| Github                                                                                     |
| ------------------------------------------------------------------------------------------ |
| [安装](https://raw.githubusercontent.com/bingwaa/qmdmb/main/qmdmb.user.js)                  |

## 功能

- 未开播的直播间也能打开面板
- 已开播但未关注/取关的直播间也能打开面板
- 亲密度与今日亲密度进度
- 亲密之旅解锁进度
- 今日亲密度增长明细：任务项、礼物项、充电/投币项

- 「粉丝团灯牌」当天首次投喂只计入任务奖励(+6)，第二次投喂才计入明细(+1)
- 在活动日(疯狂星期五/注水日)亲密度计算可能会出错
- 只适用于日常记录亲密度增长，请以自己实际情况为准
