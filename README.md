# B站直播间亲密度面板

- 在直播间顶栏增加一个按钮，能在任何状态(直播中/未开播/未关注)直播间打开亲密度面板
- 适用于在未开播直播间查看亲密度任务完成情况
- 适用于拧巴观众取关了主播但还想刷牌子亲密度

## 安装

需要先安装 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)。

点击下方表格中的链接即可安装：

## 功能

- 未开播的直播间也能打开面板
- 已开播但未关注/取关的直播间也能打开面板
- 亲密度与今日亲密度进度
- 亲密之旅解锁进度
- 今日亲密度增长明细：任务项、礼物项、充电/投币项
- 非大航海用户也能显示总观时和总发送弹幕数
